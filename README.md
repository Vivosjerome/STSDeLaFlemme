# STS de la flemme

Page pour envoyer sa journée sur [STS Mobilité](https://sts-mobilite.stsweb.fr/) sans lancer la validation finale. Chaque personne se connecte avec son propre compte.

L’email et le mot de passe restent sur l’appareil, et la page se reconnecte toute seule. Déconnexion les efface. Aucun identifiant ne doit être commité.
